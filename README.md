## About

I'm **Prabin Kandel**, a developer and project maker from Pokhara, Nepal, interested in web development, software, and technology-driven solutions.

I enjoy taking ideas seriously enough to build them. Whether I'm designing an interface, connecting application components, working with data, or investigating why something isn't working as expected, I approach development as a process of learning, testing, and improvement.

## Selected Projects

### Hire-Nepal

A recruitment platform project focused on job opportunities in Nepal.

The project explores how a web-based platform can bring job-related information and recruitment workflows together in one place.

**Project:** [View Hire-Nepal](https://prabinkandel1.github.io/Hire-Nepal/)

### Prometheus X

An environmental monitoring project combining hardware-collected data with a web-based software interface.

The software side focuses on presenting environmental readings in a way that makes collected information easier to observe and understand. The project is being developed further as its software and integrations evolve.

**Focus areas:** Environmental monitoring, data visualization, and hardware–software integration.

## Development Approach

- **Build with purpose:** Focus on what a project is intended to accomplish.
- **Investigate problems:** Research issues and work toward understanding their causes rather than abandoning a project at the first obstacle.
- **Learn by building:** Develop practical skills through experimentation and real project work.
- **Improve continuously:** Refine functionality, usability, structure, and presentation as projects evolve.
- **Be accurate:** Represent project capabilities honestly and distinguish working features from planned improvements.
